# Minecraft Expansion Mod

## Overview
This project is a custom Minecraft mod designed to expand the game's creative and gameplay possibilities.  
It introduces **10+ new items, blocks, and mechanics**, giving players fresh tools and systems to experiment with in their worlds.

## Purpose & Context
This mod was created as part of a personal learning project to deepen my understanding of:
- Java development
- The **Forge** modding framework
- Game asset creation and data-driven design

While developing this mod, I aimed to enhance player creativity and engagement by adding meaningful features that integrate naturally with vanilla Minecraft.

## Features
- **New Items:** Custom tools, materials, and interactive items  
- **New Blocks:** Decorative and functional blocks with unique behaviors  
- **Gameplay Mechanics:** Added systems that enrich exploration and crafting  
- **Data Generation:** Automated data creation (loot tables, recipes, block states, etc.) to speed up development and maintain consistency  

## Development Details
- Built with **Java**, using the **Forge API**
- Developed and tested in **IntelliJ IDEA**
- Implemented **custom data generation classes** to streamline JSON creation and reduce manual errors
- Followed modding best practices to ensure stable performance and compatibility

## Skills & Technologies Used
- Java  
- Forge Modding API  
- IntelliJ IDEA  
- Asset/Data Generation  
- Debugging & Testing in a modded environment
